# Transit Light-Curve MCMC and Published-Parameter Comparison

## Summary

Prepare transit photometry, infer shared and per-transit parameters, and quantify agreement with published values.


## When to use

Use when one or more photometric transit light curves must be detrended, fitted jointly with a transit-and-noise MCMC model, and compared with an external table of published transit parameters.


## When NOT to use

- The data is not this platform.
- You need a single atomic step, not the full pipeline (use the leaf skill directly via the router).

## Stages

### Stage 1 — prepare_lightcurve

**Goal:** normalize and detrend transit photometry while preserving transit signals

**EDAM operation:** http://edamontology.org/operation_0334

**Inputs:** observation-table/transit-photometry · **Outputs:** lightcurve/detrended-transit

**Candidate leaf skills:** `stellar-lightcurve-detrending` (primary), `orbital-period-measurement-from-transit-epochs`, `exoplanet-transit-photometry-modelling`, `multi-instrument-lightcurve-joint-fitting`

**Tools (primary):** CHEOPS, Python, TESS, plaNETic


**Grounding:** 1 KB(s); DOIs: 10.1051/0004-6361/202450472

### Stage 2 — fit_transit_posterior

**Goal:** jointly fit transit shape and correlated photometric noise

**EDAM operation:** http://edamontology.org/operation_3799

**Inputs:** lightcurve/detrended-transit, configuration/transit-model · **Outputs:** posterior-samples/transit

**Candidate leaf skills:** `mcmc-transit-light-curve-fitting` (primary), `multi-transit-simultaneous-fitting-with-locked-parameters`, `simultaneous-multi-transit-parameter-sharing`

**Tools (primary):** EXOFAST, IDL, IDL (Interactive Data Language), Transit Analysis Package (TAP)


**Grounding:** 1 KB(s); DOIs: 10.1155/2012/697967

### Stage 3 — compare_published_parameters

**Goal:** quantify agreement between inferred and published transit parameters

**EDAM operation:** http://edamontology.org/operation_2422

**Inputs:** posterior-samples/transit, parameter-table/published-transit-reference · **Outputs:** parameter-table/transit-comparison, diagnostic-report/published-agreement

**Candidate leaf skills:** `cross-survey-transit-parameter-comparison` (primary), `transit-parameter-comparison-across-publications`, `published-transit-parameter-agreement-verification`, `mcmc-posterior-parameter-estimation--625da6f013605ea9`

**Tools (primary):** EXOFAST, IDL, Transit Analysis Package (TAP)
