# cmb-likelihood-evaluation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Evaluates the Planck CMB likelihood of reheating-consistent slow-roll predictions generated by ASPIC/libaspic for single-field inflation models, enabling Bayesian evidence computation and model ranking as described in Encyclopædia Inflationaris.

## When to use

Use when comparing theoretical predictions (spectral observables) of single-field inflationary models against publicly available Planck CMB likelihood data to compute per-model likelihoods and Bayesian evidences.

## When NOT to use

- The goal is only to produce slow-roll predictions without data comparison — building and running ASPIC (make check/make test) suffices, no CMB likelihood is needed
- Non-single-field or non-slow-roll inflation scenarios, which are outside the class of models supported by the ASPIC library
- When no Planck CMB likelihood data is available and evidences cannot be integrated over priors

## Inputs

- libaspic slow-roll predictions: spectral observables per model over the model prior grid (reheating-consistent)
- Publicly available Planck CMB likelihood data
- Prior parameter ranges for each inflationary model
- A reference model for defining Bayes factors

## Outputs

- Per-model Bayesian evidence values
- bayesian_evidence_ranking.csv: one row per selected model with evidence values and a ranking column ordering models monotonically by evidence

## How to apply

For each selected inflationary model, run the ASPIC slow-roll routines (libaspic, built from github.com/cosmicinflation/aspic) over the model prior grid to generate reheating-consistent observable predictions (e.g. spectral observables) as the forward model. Load the publicly available Planck CMB likelihood data and evaluate the likelihood of each model's predicted observables. Compute the Bayesian evidence for each model by integrating the CMB likelihood over the model's prior parameter space with MCMC or nested sampling, which includes the Occam penalty from prior volume. Rank models by their computed evidences as Bayes factors relative to a reference model. Write the comparison to bayesian_evidence_ranking.csv.

## Related tools

- **ASPIC** (Runtime library providing routines to derive reheating-consistent observable predictions for slow-roll single-field inflation models, used as the forward model for the CMB likelihood evaluation) — https://github.com/cosmicinflation/aspic
- **libaspic** (Shared Fortran scientific library compiled with gfortran (OpenMP parallelism via '-fopenmp') that computes the slow-roll predictions fed into the likelihood) — https://github.com/cosmicinflation/aspic
- **gfortran** (Open-source Fortran compiler used to build libaspic; FORTRAN08 complex atan() support may require fallback FCFLAGS="-DNOF08")
- **OpenMP** (Parallel processing enabled by default via the '-fopenmp' flag to speed up evaluating predictions over model prior grids)

## Examples

```
./configure && make && make install && man libaspic
```

## Evaluation signals

- bayesian_evidence_ranking.csv exists and is a valid CSV file
- The table contains one row per selected model, each with finite evidence values
- The ranking column orders models monotonically by evidence
- Each model's slow-roll predictions are reheating-consistent (generated over the model prior grid via ASPIC routines)
- Sanity check: rebuilding libaspic with 'make test' passes so that the forward-model predictions are reproducible before likelihood integration

## Limitations

- Numerical precision limits: some models require extreme fine-tunings and may need quadruple-precision compilation (--enable-quad-precision, producing libaspicq), which is much slower
- FORTRAN08 complex atan() calls can error with some compilers; workaround is export FCFLAGS="-DNOF08"
- Evidence computation is expensive: integrating the CMB likelihood over the full prior volume (MCMC/nested sampling) plus the Occam penalty is much slower than generating predictions alone
- The evidence ranking covers only the subset of models selected; ASPIC currently supports 74 models, and models not implemented must be added by the user
