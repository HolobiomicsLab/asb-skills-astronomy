# rotation-curve-visualization

## Summary

Visualise the rotation-curve and tracer-position data products generated by galkin_data.py using the ready-to-use galkin_plotter.py script, which renders the spatial distribution of the kinematic tracers (gas, stars, masers) and the inferred Milky Way rotation curve via the galkin package's matplotlib plotting backend.

## When to use

Use when you have galkin output files (output/vcdata.dat and output/posdata.dat) from a galkin_data.py run and need demonstrative figures of tracer spatial distribution and the Milky Way rotation curve.

## When NOT to use

- The goal is to re-run galkin repeatedly on the fly (e.g. scanning over input parameters) without file I/O — use galkin_data_fast.py instead of the file-based retrieve-then-plot workflow
- You intend to plot the original kinematic data directly from galkin/data/data_*.dat — the README caveats that these contain original published, non-normalised data and should not be used unless fully aware of each reference's assumptions

## Inputs

- output/vcdata.dat — rotation curve data file produced by galkin_data.py
- output/posdata.dat — positional data file produced by galkin_data.py

## Outputs

- Rendered figure showing the spatial distribution of the kinematic tracers (gas, stars, masers)
- Rendered figure showing the Milky Way rotation curve over Galactocentric radii between 3 and 20 kpc

## How to apply

First run galkin_data.py with the default (baseline) Galactic parameter setup to produce output/vcdata.dat (rotation curve data) and output/posdata.dat (positional data). Then invoke the ready-to-use plotter with 'python galkin_plotter.py output/vcdata.dat output/posdata.dat', which relies on the galkin package's plotting module (galkin/plots.py) and requires the matplotlib and numpy packages under python 2.7.6 or higher. The script renders two figure families: the spatial distribution of the kinematic tracers (gas, stars, masers compiled as 2780 measurements) and the rotation curve optimised for Galactocentric radii between 3 and 20 kpc. Save the rendered figure files and validate them against the baseline references output/vcdata_baseline.dat and output/posdata_baseline.dat provided with the distribution.

## Related tools

- **galkin_plotter.py** (Ready-to-use plotter script that consumes vcdata.dat and posdata.dat and produces the tracer-distribution and rotation-curve figures) — github.com/galkintool/galkin
- **galkin** (Python package providing the data-handling and plotting routines (plots.py) invoked by galkin_plotter.py) — github.com/galkintool/galkin
- **matplotlib** (Required plotting backend used by the galkin package's plotting functions to render the figures)
- **galkin_data.py** (Upstream data retriever that generates the vcdata.dat and posdata.dat input files the plotter consumes) — github.com/galkintool/galkin

## Examples

```
python galkin_plotter.py output/vcdata.dat output/posdata.dat
```

## Evaluation signals

- Each rendered figure file exists and is a readable image after running galkin_plotter.py
- Plotted data points/curve are consistent with the baseline reference files output/vcdata_baseline.dat and output/posdata_baseline.dat used for checking purposes
- Input files output/vcdata.dat and output/posdata.dat were freshly produced by galkin_data.py with the default (baseline) Galactic parameter setup
- Rotation-curve figure covers the optimised Galactocentric radius range of 3–20 kpc and includes gas, star and maser tracer populations
- The command runs without missing-dependency errors, confirming matplotlib and numpy are installed under python 2.7.6 or higher

## Limitations

- Raw data output (output/rawdata.dat and the data/data_*.dat files) is given as in the original references and is not normalised to the selected input parameters — plotting raw data directly can be misleading without awareness of each original reference's assumptions and nomenclature
- Requires python 2.7.6 (or higher) with matplotlib and numpy installed; the wx package is additionally required only for the user-friendly window mode of galkin_data.py
- The plotter is a demonstrative/ready-to-use script handling only the output of galkin_data.py, not a general-purpose plotting tool for arbitrary rotation-curve datasets
