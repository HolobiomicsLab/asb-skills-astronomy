# cme-profile-histogram-visualization

## Summary

Post-processes OSPREI simulation output: processOSPREI.py reads the standardized output text files (e.g., from ANTEATR-PARADE ensemble runs) into a results object and automatically generates profile-versus-distance plots and histograms of profile quantities (transit times, durations, densities, central B) for single-run and ensemble cases.

## When to use

Use when OSPREI (ForeCAT/ANTEATR-PARADE/FIDO) runs have completed and standardized output files exist, and you need histograms of ensemble profile quantities or distance profiles, e.g., arrival-time/duration/density/B distributions.

## When NOT to use

- You only ran a single (non-ensemble) simulation and need histograms — histograms are generated for full ensembles; use the distance-profile figures instead
- You are quickly testing a configuration and want fast figures — contour and ensemble correlation plots are computationally heavy and should be commented out
- Your data is not from OSPREI's standardized output files (e.g., raw coronagraph or OMNI observations) — this processing step is specific to OSPREI outputs

## Inputs

- OSPREI input text file (date, time, suffix, models) that named the run, e.g. an ANTEATR-only run with models=ANT
- Standardized OSPREI output files generated by the ForeCAT/ANTEATR-PARADE/FIDO runs, grouped in folders by date and tagged by suffix
- Optional .ens ensemble definition file (when nRuns > 1) that set the varied parameters and ranges

## Outputs

- Results object containing all simulation data in an easily accessible format for building custom figures
- Profile plots of quantities versus distance (single simulations)
- Histograms of profile quantities (ensemble runs), e.g., transit time, duration, density, central B distributions
- Optional contour plots and ensemble correlation plots (computationally expensive)

## How to apply

Run `processOSPREI.py` passing the same input text file used for the OSPREI run (e.g., with date, time, suffix, and models=ANT); it reads the standardized output files, assembles a results object holding all simulation data, and generates figures that differ by run type: profile plots versus distance for a single simulation, histograms for a full ensemble. Key decision point: contour plots and ensemble correlation plots are computationally heavy, so comment them out when iterating quickly during testing. New figures can be built from the results object, which exposes all simulation data in an accessible format. For validation of an ANTEATR-PARADE ensemble, confirm the emitted CSV contains mean transit times (~18:28 UT 12 May 2021; ~01:47 UT 25 Apr 2021), mean durations (36 and 27 hr), mean densities (11.1 and 5.8 cm^-3), and central B (18 vs 8 nT), each within reported ranges.

## Related tools

- **OSPREI** (Main suite whose runs produce the standardized output files; its processOSPREI.py script performs the histogram/profile visualization and builds the results object) — https://github.com/ckay314/OSPREI
- **ANTEATR (PARADE)** (Produces the interplanetary propagation/expansion profiles (speeds, angular widths, aspect ratios, internal B and temperature) whose distributions are histogrammed in ensemble mode) — https://github.com/ckay314/OSPREI

## Examples

```
python processOSPREI.py OSPtestcase.txt
```

## Evaluation signals

- The emitted CSV contains mean transit times (~18:28 UT 12 May 2021; ~01:47 UT 25 Apr 2021), mean durations (36 and 27 hr), mean densities (11.1 and 5.8 cm^-3), and central B (18 vs 8 nT) each within reported ranges
- A results object is returned containing all simulation data in an easily accessible format (spot-check that profile quantities match the output text files)
- Ensemble runs yield histograms of the profile quantities; single runs yield profiles of values versus distance
- Figures respect the date/suffix naming (files grouped in date folders with the suffix subscript, no overwriting of other configurations)
- Quick-iteration runs skip the heavy contour/ensemble correlation plots when those figure blocks are commented out

## Limitations

- Contour plots and ensemble correlation plots require significant computation and may need to be commented out for quick figure generation
- Only two CME cases (22 April and 09 May 2021) were validated; more cases are needed to establish the model
- The skill visualizes whatever the run produced — e.g., FIDO-SIT cannot predict in situ magnetic field components, only a Parker Spiral orientation, so those figures reflect that assumption
