# kp-index-prediction-comparison

## Summary

Predict the geomagnetic Kp index from synthetic in situ profiles generated by FIDO (within OSPREI) and compare the predicted maximum Kp against OMNI observations to validate a CME forecast, including requiring the maximum Kp to occur in the model's FIDO-SIT sheath.

## When to use

Use when validating Sun-to-Earth CME ensemble forecasts that need a predicted geomagnetic response: run FIDO over a synthetic spacecraft, extract the maximum Kp from the ensemble in situ profiles, and check it against observed OMNI Kp for the event.

## When NOT to use

- When only an arrival time or speed forecast is needed without magnetic field or geomagnetic response, since the Kp comparison requires the full ForeCAT-ANTEATR-FIDO chain
- When observations other than the OMNI-recorded Kp/shock arrival for the target event are the validation reference, as the overlay and thresholds (3 hr arrival, sheath Kp) are defined against OMNI data

## Inputs

- ANTEA/ANTEATR ensemble outputs (evolved CME position, orientation, speed, size, shape)
- OSPREI input text file with date, time, suffix, models=FIDO, satellite position parameters, includePUP=True
- Optional .ens ensemble parameter-range file
- OMNI observational data file supplied via ObsDataFile
- HMI synchronic magnetogram-derived PFSS background pickles (ForeCAT prerequisite)

## Outputs

- Per-ensemble-member synthetic in situ profiles of magnetic field, velocity, and Kp index at the synthetic spacecraft
- Ensemble histograms and probability contour plots of predicted Kp and B properties
- Verification table comparing predicted shock arrival time, maximum B, most negative Bz, and maximum Kp (with sheath occurrence) against OMNI observations

## How to apply

Configure the OSPREI input text file with date, time, suffix, and models set to the FIDO component, specify the satellite position (SatLat, SatLon, SatR, SatRot or a .sat path file), and set includePUP=True to activate the FIDO-SIT sheath, since the validation requires the maximum Kp to occur in the sheath. Run FIDO on ANTEA(TEATR) ensemble outputs so each ensemble member's evolved CME (position and orientation from ForeCAT) passes over the synthetic spacecraft, producing per-member magnetic field, velocity, and Kp profiles. Process the standardized output files with processOSPREI.py to obtain in situ profile figures and ensemble histograms/probability contours, overlaying OMNI observations via ObsDataFile. Judge correctness by checking that the ensemble-mean shock arrival time is within 3 hr of the observed value and that the maximum Kp falls in the sheath region of the synthetic profile for both CME cases (09 May 2021 and 22 April 2021).

## Evaluation signals

- Ensemble-mean predicted shock arrival time falls within 3 hr of the OMNI-observed arrival for both CME 1 (09 May 2021) and CME 2 (22 April 2021)
- Maximum Kp occurs in the sheath (FIDO-SIT) portion of the synthetic in situ profile
- Maximum B is 16±3 nT for CME 1 and 11±1 nT for CME 2; most negative Bz is −11±2 nT and −2±1 nT, respectively
- Overlay of OMNI data via ObsDataFile visually aligns with the synthetic Kp/B/velocity profiles in the processOSPREI.py figures
- Results object from processOSPREI.py populates the verification table without missing per-member profiles

## Limitations

- FIDO-SIT cannot predict the actual in situ magnetic field components; only a Parker Spiral orientation is assumed for the upstream direction
- The background solar wind is one of the most under-developed components of OSPREI and its effect on results is untested
- Only two CME cases were used, so validation of the Kp/sheath criterion rests on a small, relatively similar sample
