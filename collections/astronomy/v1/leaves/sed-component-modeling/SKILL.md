# sed-component-modeling

## Summary

Builds composite galaxy ultraviolet-to-millimetre spectral energy distributions by scaling and summing templates drawn exclusively from four pre-computed radiative transfer model libraries (starburst, AGN torus, host galaxy, polar dust), as used in the SMART SED fitting code.

## When to use

Use when reconstructing or decomposing a galaxy SED into starburst, AGN torus, host galaxy, and polar dust radiative transfer components, e.g. to reproduce SMART's model space before Bayesian MCMC fitting.

## When NOT to use

- The SED fitting should be driven by non-radiative-transfer energy balance methods — SMART's model space is assembled exclusively from radiative transfer libraries, so this composition approach does not apply to purely empirical or parametric energy balance SED codes.
- The target is an individual library template rather than a multi-component composite SED summing starburst, AGN torus, host galaxy, and polar dust contributions.

## Inputs

- Pre-computed radiative transfer model libraries from the SMART v1.0 release archive (SMART_v1.0.7z / SMART_v1.0_mac.7z)
- User specification of library component selections (starburst, AGN torus, host galaxy, polar dust templates to combine)

## Outputs

- Composite multi-component ultraviolet-to-millimetre SED generated by component_combination.py

## How to apply

Obtain the SMART v1.0 release archive (SMART_v1.0.7z for Windows/Linux, SMART_v1.0_mac.7z for macOS) and extract the pre-computed radiative transfer model libraries. Load the four library types (starburst, AGN torus, host galaxy, polar dust) in Python 3.10, following SMART_User_Manual.pdf for the library formats. Implement the component-combination function so each user-selected library template is scaled and the components are summed into a single composite ultraviolet-to-millimetre SED, mirroring the model space SMART fits with a Bayesian Markov chain Monte Carlo method. Validate by running the module end-to-end on user-specified component selections and confirming the output SED is assembled exclusively from the four radiative transfer library types.

## Related tools

- **SMART** (Open-source SED fitting code whose four pre-computed radiative transfer libraries (starburst, AGN torus, host galaxy, polar dust) define the component model space being composed; distributed as SMART_v1.0.7z with SMART_User_Manual.pdf for library formats.) — https://github.com/ch-var/SMART.git
- **Python 3.10** (Development environment (Anaconda package) in which the component-combination function loads, scales, and sums the four library templates into the composite SED.)

## Examples

```
python component_combination.py --components starburst,agn_torus,host,polar_dust --output composite_sed.dat
```

- Scaling check: each selected library template contributes a scaled component to the summed SED, matching user-specified component selections

## Limitations

- Model space is restricted to four pre-computed library types — starburst, AGN torus, host galaxy, and polar dust — so components outside these radiative transfer libraries cannot enter the composite SED.
- SMART v1.0 ships as separate archives per operating system (SMART_v1.0.7z for Windows/Linux, SMART_v1.0_mac.7z for macOS); the correct archive must be selected and extracted before libraries can be loaded.
- The code targets Python 3.10 (Anaconda package); other environments are not covered by the release or the manual.
