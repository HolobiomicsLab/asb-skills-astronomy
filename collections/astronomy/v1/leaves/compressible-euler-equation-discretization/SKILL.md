# compressible-euler-equation-discretization

## Summary

Method for discretizing the 2-D compressible isothermal Euler equations (closed by p = c_s^2 * rho) with axisymmetric galactic-potential and rotating-weak-bar source terms on a Cartesian finite-volume grid, as implemented in the galax2d Matlab package (Mulder 2015), to obtain a stationary barred-galaxy gas flow.

## When to use

Use when a stationary 2-D gas flow in a galactic potential with a rotating weak bar must be computed by discretizing the compressible isothermal Euler equations, or when reproducing the galax2d solver behavior.

## When NOT to use

- The flow is non-isothermal or requires an energy equation / shock heating — galax2d closes the system with p = c_s^2 * rho only.
- The goal is a fully time-dependent evolution rather than a stationary solution forced by a rotating weak bar.
- The bar is strong or the domain is 3-D — outside the 2-D weak-bar regime the paper parameterizes.

## Inputs

- Parameter file g2myparms.m (grid extents, sound speed, bar strength, bar pattern speed) matching ./paper/paper.pdf
- Matlab 8.0 (R2012b) or later environment with the galax2d package (run/ directory, figures4paper/)
- Initial gas state (density and momentum fields) on the 2-D Cartesian grid; a homogeneous state for the consistency check

## Outputs

- Stationary 2-D density and velocity fields solving the isothermal Euler equations with galactic-potential and rotating-bar source terms
- Verification metrics: max-norm residual of the stationary equations and conservation error, written to solver_test_results
- Paper figures regenerated by makefigs from figures4paper/ (optional)

## How to apply

Implement the isothermal closure p = c_s^2 * rho directly in the density and momentum flux functions, since this model carries no energy equation. Add the source terms as gravitational acceleration from the axisymmetric galactic potential plus the perturbation of a rotating weak bar evaluated at the bar pattern speed. Discretize with a conservative finite-volume update on a Cartesian 2-D grid — numerical fluxes at cell faces, explicit time step satisfying the CFL condition — and impose outflow/fixed boundary conditions consistent with the galactic domain so the bar-driven flow is well posed. Set the grid extents, sound speed, bar strength and pattern speed in g2myparms.m to match the parameter list in ./paper/paper.pdf, then run the reference implementation from the packaged run directory with `cd run; g2test;` under Matlab 8.0 (R2012b) or later, allowing one or two hours. Validate by initializing a homogeneous state and verifying the discrete update preserves it (flux/source balance), and confirm a short integration reduces the max-norm residual of the stationary equations; write the max-norm residual and conservation error to solver_test_results.

## Evaluation signals

- A homogeneous initial state is preserved by the discrete update (numerical fluxes and source terms balance exactly).
- A short integration reduces the max-norm of the residual of the stationary equations, recorded in solver_test_results.
- Conservation error (mass/momentum drift) stays within the tolerance recorded in solver_test_results.
- g2myparms.m reproduces the parameter set listed in ./paper/paper.pdf (grid extents, sound speed, bar strength and pattern speed).
- A full g2test run completes under Matlab 8.0 (R2012b)+ within the expected one-or-two-hour window without runtime errors.

## Limitations

- Isothermal closure only (p = c_s^2 * rho): no energy equation, so non-isothermal or shock-heated flows are out of scope.
- Targets a stationary solution forced by a rotating weak bar; strong-bar or inherently time-dependent regimes are not covered.
- Requires Matlab 8.0 (R2012b) or later; a single g2test run takes one or two hours depending on Matlab version and hardware.
- No changelog found for the galax2d repository, so version drift against the paper cannot be traced.
