# arrival-time-histogram-generation

## Summary

Use OSPREI's post-processing routine, processOSPREI.py, to automatically convert the standardized output data files from an OSPREI (ForeCAT + ANTEATR + FIDO) run — including ensemble runs — into user-friendly figures such as arrival-time histograms, parameter-versus-distance profiles, in situ probability contour plots, and ensemble correlation plots.

## When to use

Use when you have completed an OSPREI run (single case or nRuns > 1 ensemble) and need to turn its systematic output files into forecaster-facing figures, e.g. arrival-time histograms and profiles.

## When NOT to use

- You need a new forecast number rather than a visualization — run OSPREI.py itself instead; processOSPREI.py only post-processes existing outputs
- You need quick turnaround figures during testing but the expensive contour/correlation figure blocks are still enabled — comment those out rather than waiting
- The underlying simulation is a single-run case and you expect ensemble-only products (probability contours, correlation plots) — those are produced for full ensemble runs

## Inputs

- Standardized output data files generated by a completed OSPREI run (single simulation or ensemble)
- OSPREI input text file (e.g. OSPtestcase.txt) with required parameters date, time, suffix, CMElat, CMElon, CMEtilt, CMEvr, CMEAW
- For ensembles: a companion .ens file with the same name as the input file setting varied parameters and ranges (nRuns > 1)

## Outputs

- Histograms of ensemble outputs (e.g. arrival time distributions) for ForeCAT, ANTEATR, and FIDO
- Profiles of parameters versus distance
- In situ probability contour plots and ensemble correlation plots (ensemble case)
- Spatial maps and coronal trajectory ensemble figures from ForeCAT positional profiles
- A results object holding all simulation data for constructing custom figures

## How to apply

Run processOSPREI.py with the same OSPREI input text file used for the simulation (e.g. 'python processOSPREI.py OSPtestcase.txt'); it loads the standardized output files and builds a results object holding all simulation data in an easily accessible format. Generate the cheap figures first: profiles of parameters versus distance and histograms for ForeCAT, ANTEATR, and FIDO ensemble outputs (for ensembles, this includes arrival-time histograms). The computationally expensive figures — in situ probability contour plots and ensemble correlation plots — are generated afterwards and can be commented out if quick turnaround figures are needed during testing. For ensemble runs (nRuns set greater than 1, with a companion .ens file varying parameters), the script adapts its figure set to the ensemble case, including spatial maps and coronal trajectory ensemble figures built from the ForeCAT positional profiles. Any additional custom figures can be constructed directly from the results object beyond the standardized set.

## Examples

```
python processOSPREI.py OSPtestcase.txt
```

## Evaluation signals

- The script completes without error when invoked with the OSPREI input text file
- Expected figure files are produced as valid image files (profiles, histograms, contour plots)
- Histograms reflect the ensemble spread: for nRuns > 1, distributions over arrival time and other outputs from the .ens-varied parameters
- Figure set matches the run type: single-simulation figures for one run, ensemble figures (contours, correlations) for ensembles
- The results object loads the standardized outputs and can be used to construct additional custom figures

## Limitations

- Some figures (contour plots and ensemble correlation plots) require significant computation and 'should potentially be commented out and not run if you want to make quick figures while testing things'
- The processOSPREI routine is separate from the main simulation; the OSPREI run itself must have completed and produced its systematic output files first
- OSPREI's visualization set is standardized; figures beyond it must be custom-built from the results object
