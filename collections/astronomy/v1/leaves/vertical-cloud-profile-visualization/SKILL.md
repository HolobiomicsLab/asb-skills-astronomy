# vertical-cloud-profile-visualization

## Summary

Visualize and interpret steady-state vertical cloud composition profiles produced by the ExoLyn 1D multispecies cloud model, using draw.py to plot condensed-species mass/number densities per altitude or pressure level and checking for the expected compositional layering.

## When to use

Use when an ExoLyn relaxation run has converged and you need to inspect, plot, or validate the vertical distribution of condensed species (e.g., MgSiO3/Mg2SiO4 over Fe) in a hot-Jupiter or other exoplanet atmosphere.

## When NOT to use

- The ExoLyn relaxation run has not converged — profiles of a non-steady-state atmosphere are not physically meaningful for layering interpretation
- You need full 3D or kinetic cloud microphysics beyond a 1D efficient model; ExoLyn is deliberately a 'golden mean' trade-off, not a replacement for more complex cloud formation models
- Gibbs formation energies for the condensing molecules are missing from gibbs.txt — the chemistry (and hence the profiles) would be incomplete

## Inputs

- cloud_composition_profile.csv with steady-state condensed-species mass/number densities per altitude/pressure level
- converged ExoLyn run state produced by relaxation.py (initialized via init.py, parameters.txt configuration)
- solid species list defined in parameters.txt (e.g., MgSiO3, Mg2SiO4, Fe)

## Outputs

- Vertical profile plots of condensed-species mass/number density vs. altitude or pressure generated by draw.py
- Visual identification of cloud layering (dominant condensate per pressure level)

## How to apply

After convergence of the relaxation driver (python3 relaxation.py, which relies on sol.f90 for solving the coupled cloud-particle and vapor transport equations), tabulate the steady-state condensed-species mass and number densities per altitude/pressure level as cloud_composition_profile.csv. Use draw.py, the README-designated plotting module, to render the vertical profiles of each solid species. Interpret the profile by identifying which condensate dominates at which pressure levels: for hot-Jupiter conditions, verify the reported layered structure with a magnesiumsilicate-dominated cloud (MgSiO3/Mg2SiO4) overlying an iron cloud. The 8–10 μm absorption feature from MgSiO3/Mg2SiO4 is a diagnostic tie-in if the profiles are later combined with optool opacities and petitRADTRANS spectra.

## Related tools

- **ExoLyn** (1D multispecies cloud model whose converged steady-state condensate profiles are visualized by this skill) — github.com/helonghuangastro/exolyn
- **draw.py** (ExoLyn's plotting module used to draw the vertical cloud composition profiles) — github.com/helonghuangastro/exolyn
- **optool** (optional downstream tool to calculate solid opacities from the condensed species identified in the profiles)
- **petitRADTRANS** (optional downstream tool to generate transmission or emission spectra informed by the cloud layering)

## Examples

```
python3 relaxation.py && python3 draw.py
```

## Evaluation signals

- The profile reproduces the reported layered structure: a cloud dominated by magnesium silicates (MgSiO3/Mg2SiO4) on top of an iron cloud for hot-Jupiter conditions
- Condensed-species mass/number densities are tabulated at every altitude/pressure level in cloud_composition_profile.csv with no missing levels
- Plot rendering via draw.py runs without errors and each solid species listed in parameters.txt appears in the profile output
- Metallicity sensitivity checks behave as reported: SiO2-dominated clouds on metal-rich planets and Fe clouds with strong extinction on C-rich planets

## Limitations

- ExoLyn is a 1D model balancing physical consistency with computational efficiency; results are consistent with more complex cloud formation models but are not a substitute for them
- Interpretation depends on complete Gibbs formation energy data in gibbs.txt for all molecules involved in the reactions (sourceable from janaf.nist.gov)
- Profiles are specific to the atmosphere parameters set in parameters.txt; changing metallicity or C/O changes which condensate dominates
