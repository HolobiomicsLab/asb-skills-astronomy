# involutive-mcmc-transition-kernel-construction

## Summary

Constructs the SMC transition (rejuvenation) step of gallifrey's Bayesian GP kernel structure learning loop: an involutive Markov chain Monte Carlo kernel that jointly updates the discrete GP kernel structure and continuous hyperparameters within JAX.

## When to use

Use when the GP covariance function cannot be fixed a priori for a time series (e.g. stellar variability or exoplanet transit flux data) and the kernel structure itself must be inferred as a latent discrete variable via SMC with involutive MCMC transitions.

## When NOT to use

- The covariance function is already known or fixed a priori and only hyperparameters need tuning — gallifrey's structure learning targets inferring the covariance structure itself from the time series.
- The dataset is very large and runtime is critical — the paper explicitly flags scalability to larger datasets (e.g. for missions like PLATO) as future algorithmic work.
- The task is not time series modelling/forecasting (e.g. purely spatial or image data) — the method is focused on time series such as stellar variability and transit light curves.

## Inputs

- Astronomical time series (time and flux measurements) loaded as numpy/pandas arrays or jnp arrays (e.g. xtrain/ytrain)
- GPConfig specifying the kernel vocabulary and prior configuration over kernel structures and hyperparameters
- Number of SMC particles, an annealing schedule (LinearSchedule), and MCMC step counts (n_mcmc, n_hmc)

## Outputs

- Final SMC state containing the posterior particle set of kernel structures and hyperparameters with SMC log weights (e.g. smc_kernel_samples.csv)
- GPModel predictive mixture distribution (predictive mean and standard deviation) from get_mixture_distribution(xtest)

## How to apply

Define a prior over kernel structures and hyperparameters (the covariance structure is treated as a latent discrete variable) and initialize an SMC particle population of kernel/hyperparameter samples, e.g. GPModel(..., num_particles=8) in gallifrey. Run the reweight–resample–rejuvenate cycle: reweight particles by the GP marginal likelihood, resample adaptively when particle weights degenerate, then rejuvenate each particle with the involutive MCMC transition kernel that jointly proposes moves in discrete structure space and continuous hyperparameter space. Invoke the transitions via gpmodel.fit_smc with an annealing schedule generated by LinearSchedule().generate(len(xtrain), 10), n_mcmc=50 MCMC steps per SMC iteration, and n_hmc=10 HMC steps within each MCMC step. The involutive construction is what makes valid joint structure+hyperparameter proposals possible; it is implemented in JAX (gallifrey is a re-implementation of Saad et al.'s AutoGP.jl). After the terminal SMC iteration, update the model state (gpmodel.update_state(final_smc_state)) to obtain the posterior mixture over kernel structures for prediction.

## Examples

```
final_smc_state, history = gpmodel.fit_smc(smc_key, annealing_schedule=LinearSchedule().generate(len(xtrain), 10), n_mcmc=50, n_hmc=10)
```

## Evaluation signals

- The fit_smc pipeline runs end-to-end in gallifrey/JAX (Python >=3.10, jax 0.5.x) without errors
- The posterior particle set is non-degenerate (particles retain distinct kernel structures; SMC log weights are meaningful)
- The annealing schedule was generated before fitting (LinearSchedule().generate(len(xtrain), 10)) — omitting it is a known prerequisite for correct SMC behaviour
- Learned structures improve accuracy and uncertainty estimation relative to fixed-kernel GP baselines (qualitative acceptance criterion from the paper; no numeric threshold reported)
- Predictions from get_mixture_distribution produce finite predictive mean and standard deviation on interpolation and extrapolation regions

## Limitations

- Scalability to larger datasets is identified as future work needed for missions such as PLATO
- The acceptance criterion for structure learning versus fixed kernels is qualitative (accuracy and uncertainty estimation); no numeric threshold is reported
- Requires a specific dependency window (blackjax >=1.2.5,<2.0.0; jax >=0.5.0,<0.6.0) and Python 3.10+
